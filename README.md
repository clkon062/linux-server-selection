# Linux云服务器：新手怎么选配置和线路，几十元档位从购买到 SSH 登录的完整流程

搜「Linux云服务器」的人，问题其实就两个：第一台机器要花多少钱才够用，买回来之后怎么把它连上。至于"数字化转型""上云趋势"这类话，跟你要买的这台机器没有关系。

下面按真实下单顺序说：先定用途，再看参数，然后是对应的价格区间、具体的购买流程，以及几个买了之后才会发现的坑。

## 先想清楚这台机器干什么

配置是被用途决定的，不是被预算决定的。

- **学 Linux、跑命令、练部署**：1 核 1G 足够，装个 Debian 或 Ubuntu，SSH 进去折腾。硬盘 10–30G 也不紧张。
- **放一个 WordPress 或小博客**：2 核 2G 起，重点在带宽，不在核心数。1M 带宽的机器打开一个带图片的页面要等好几秒，这不是配置问题，是物理限制。
- **跑机器人、爬虫、小型 API 服务**：内存是瓶颈。Node、Python 这类运行时加上数据库，2G 很容易在跑一周后被 OOM 干掉，4G 会舒服很多。
- **编译、跑游戏服、跑需要单核性能的任务**：看 CPU 型号比看核心数重要。同样 4 核，一颗高主频处理器和一颗低频服务器 U，跑 Minecraft 服的实际差距能有好几倍。

把这四个场景对一遍，你会发现自己真正需要的档位比预想的低——大部分个人项目用不上 8 核 16G，也跑不满 100M 带宽。

## 四个参数决定你有没有花冤枉钱

**CPU 型号**。云服务商的配置表通常按型号分线，比如雨云把 AMD EPYC 7A23 定位成单核高频优化、EPYC 7702 定位成多核高并发、Xeon Platinum 定位成稳定高性能、Xeon Gold 定位成通用均衡。选之前先确认这档用的是哪颗 U，同样的价格可能差出一代。

**计费方式：流量叠加型还是不限流量型**。这个是最容易被忽略的一项。流量叠加型的特点是每月用不完的流量会自动累计到下个月（次月不清零），用完就限速，可以另外买流量包恢复；不限流量型则把上行带宽压得比较低，用带宽换流量的确定性。做下载站、图床、视频这类流量不可控的业务，不限流量型省心；流量稳定且不大的站点，叠加型更划算。

**硬盘类型**。SSD/高速 NVMe 和高效云盘（机械盘加 SSD 缓存）差距很大。雨云的价目是 SSD 云盘扩容 0.4 元/G/月、高效云盘 0.1 元/G/月，后者便宜四倍，但随机读写性能是另一个量级。跑数据库、跑面板、跑编译，别省这四倍差价。

**线路和延迟**。同样叫"香港云服务器"，优化三网、极速三网、IIJ 大带宽、国际大带宽是四条不同的线路，价格和国内访问体验都不一样。部署面向国内用户的业务，节点选择和 CPU 选择一样重要。

## 两个前置条件：备案和 NAT

这两个不解决，买了机器也用不起来。

国内节点用来放有域名的网站，域名要先备案；海外节点免备案。所以如果你不打算走备案流程，香港、东京、洛杉矶、法兰克福、首尔这几个方向的节点是唯一可行的选项。

另一个是 NAT 机型。雨云的江苏宿迁和重庆节点提供 NAT 方案，价格低是因为不带独立公网 IP，需要自己设置端口映射，适合内网穿透、学习练手，但**不能直接拿来建站**。独立 IP 是可以加购的，普通 IP 通常是 5 元/个/月，部分高防机房的独立 IP 贵得多——宿迁的独享 150G 高防 IP 是 150 元/月，湖北十堰的独享 100G 高防 IP 是 50 元/月，温州的双线高防 IP 是 60 元/月。看到"9.9 元一个月"的国内高防机器，先确认这个价格里有没有 IP。

## 从注册到 SSH 登录，实际流程长这样

这是买一台 Linux 实例的完整顺序，跟具体选哪家服务商无关：

1. **注册并实名认证**。国内服务商基本都要求实名，雨云也是，购买前得先完成这一步，否则付不了款。
2. **进控制台的云产品入口，选云服务器**。
3. **选区域和线路**。免备案需求优先香港、东京、洛杉矶；国内建站选温州、宁波、绍兴、宿迁这类节点，同时确认独立 IP 和备案。
4. **选 CPU 型号和配置档位**。按前面的用途判断来选，不要先看价格再看配置。
5. **选计费模式**。大陆大带宽节点通常提供"流量叠加型"和"不限流量型"两种，按你的流量特征选。
6. **选系统镜像**。Debian、Ubuntu、AlmaLinux、CentOS 系都能选；不想手动装环境的话，可以选预装宝塔、1Panel 或 Docker 的镜像，开机即用。
7. **选购买时长**。年付通常有折扣，雨云是年付 7 折。
8. **支付后回控制台**，等状态变成"运行中"，复制公网 IP 和 root 密码，用 `ssh root@你的IP` 登进去。

不放心的话，下单前可以先花 1 元试用一天，跑个 Geekbench 或者干脆装个环境试试手感，觉得不合适再买正式套餐。👉 [从这个入口进去可以先看 1 元试用和首月优惠](https://www.rainyun.com/MzA2MTc2_)

## 买了之后才会发现的几个坑

**流量用完不是停机，是限速。** 流量叠加型的套餐，用超之后带宽会被压到很低（不同节点是 1M 或 5M），站点不会挂，但慢到没法用。可以单独加购流量包恢复。做流量敏感业务的话，这一项要在购买前算清楚。

**退订有前提条件。** 雨云提供 7 天无理由退款，每个账号限 3 次，但已经领过产品消费积分、续过费、改过配置（升降级、加购 IP）的订单不能退；1 元试用、流量包、IP 加购、弹性云盘扩容这些非月付场景也不支持退订。想试水的话，顺序是先用 1 元试用，再决定买不买。

**试用机不是生产机。** 试用产品到期后 12 小时内不续费会自动回收，同一地域每周只能试用 1 次。别把还在跑的东西放在试用机上。

**低价档位的带宽和 IP 要单独看。** 中文主机圈常见的情况是：套餐价里不含独立 IP，或者带宽是"峰值带宽"不能长时间占用。购买页上的每一项加购价格都要点开看一眼。

**NAT 机型不适合建站。** 宿迁、重庆的 NAT 方案价格低，但没有独立公网 IP，只能做端口映射，用途是内网穿透和学习，不是放网站。

## 什么情况下不该选这类低价服务商

国内主流云厂商的价格里，有相当一部分买的是合规能力和企业服务：备案协助、等保支持、发票和合同流程、SLA 赔付、7×24 真人售后。雨云这类中小型 IDC 的定位在另一个方向——价格低、区域多、配置灵活，有工单和在线客服，也有知识库和教程，但它满足不了企业采购时那一整套流程要求。

如果你是要放公司业务、需要正规发票和书面 SLA、或者要过等保，那这条路走不通，直接去找大厂。如果是个人项目、学习环境、小站点、游戏服、跨境业务，几十元一个月的档位确实能把你需要的东西跑起来——先花 1 元试用一天，比看十篇评测都直接。
